# 仕兔改版 · 风格规范（第 04 轮：定全端风格）

> PROTOTYPE — 一次性原型的依据，不是正式设计文档。用户此轮要**先定风格**：同一界面在三个风格之间只换视觉，结构和内容保持一致；同一风格在四个界面之间必须一眼看出是一套。

## 0. 调研结论（参考截图见 `references/index.html`）

- 行业主色只有三类：蓝（智联 `#006AFF`、鱼泡 `#1C5DFF`、安心云人事 `#2B69FB`）、橙（前程无忧 `#FF6314`、58 同城 `#FF552E`、华辉人力 `#F86B24`）、青（BOSS 直聘 `#00BEBD`）。
- 共同做法（三个方向都要用）：浅灰底 + 白卡片；主色只用在主按钮、选中态和少量强调；薪资用醒目暖色、写成「5,800–6,800 元/月」而不是「6–7K」；福利用灰底小标签（包吃、包住、长白班、可预支）；详情页底部吸底通栏主按钮；手机端底部 4 个标签；企业端「左侧图标侧栏 + 数字概览 + 待办」；「打电话」是驻场的一级动作。
- 一律避开：首屏广告横幅、下载 App / 登录弹窗、到处的角标和「HOT」、整屏高饱和色块、渐变和 3D 玻璃、营销海报式插画、12px 以下小字、浅灰低对比文字。
- 给大众用：正文不小于 14px（手机端 15px），重要数字（薪资、倒计时）加粗放大，文案口语化，一屏一个主动作。

## 1. 三个方向共用的规则

- 字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif`；数字 `font-variant-numeric: tabular-nums`。不引用任何网络字体。
- 字号层级（PC / 手机）：页面标题 20/18 · 区块标题 16/16 · 正文 14/15 · 辅助 13/13 · 最小 12/12。字重只用 400 / 500 / 600。
- 间距：4 的倍数；手机页面左右边距 16，卡片内边距 16，卡片间距 12；PC 主区边距 24，卡片间距 16。
- 图标：一套线性图标，1.75 描边，内联 SVG（可照搬 `a2-list-detail.html` 里的 symbol），不用 emoji、不用位图。
- 品牌标：沿用现有造型（见 `a2-list-detail.html` 侧栏里的 svg），方块颜色换成该方向的主色。文字「仕兔」。
- 中性色（三个方向相同，D2 底色略暖除外）：文字 `#1A1D23` / `#4B5260` / `#8A909C`（禁止更浅的正文色）、边框 `#E6E8EC`、分隔线 `#F0F1F3`、白卡片 `#FFFFFF`。
- 状态色：危险 `#E5484D`、提醒 `#E8890C`、成功 `#18A058`。
- 归属标签（只在公司后台和驻场端出现，求职者端绝不出现「私域 / 公域 / 确权」字样）：私域 底 `#FFF3E0` 字 `#B45309`；公域 底 `#E6F7F5` 字 `#0F766E`（D3 绿色方向里公域改为 底 `#EAF1FF` 字 `#2453C7`，避免和主色撞）；报名中 底 `#F1EBFD` 字 `#6D3FD1`。
- 求职者端对应说法：「自由求职」（公域）、「专属服务 · 鑫诚劳务」（私域）、「报名中」。
- 禁止：渐变、毛玻璃、阴影大于 `0 1px 3px rgba(0,0,0,.06)`（浮层除外）、装饰插画、广告位、假数据冒充业绩（不写「服务 xx 万人」这类数字）。

## 4. 各界面的结构（三个方向结构相同，只换视觉）

### 4.1 官网首页（桌面 1440 宽，可向下滚动，做 4–5 屏）
1. 顶栏：品牌标 + 导航（求职者、劳务公司、关于我们）+ 右侧「登录」文字链和「劳务公司入驻」主按钮。
2. 首屏：左侧大标题（例如「工厂找活，1 分钟出 3 个靠谱岗位」）+ 副标题 + 两个按钮（主：「劳务公司申请入驻」；次：「我要找工作」并配一个求职者扫码的二维码占位方块，用 svg 画简化二维码图形即可）。右侧放一张用 HTML 实际搭出来的求职者端手机画面（匹配结果卡片），不要用图片、不要倾斜。
3. 求职者三步：做 7 道题 → 看 3 个岗位 → 报名后 24 小时有人联系。
4. 给劳务公司的四个能力：渠道码锁定来源、驻场工作台、人才流转收益、全流程在线签约；配一张用 HTML 搭的后台缩略画面。
5. 规则透明：费用说明（0.10 元/人/天，前三个月免费；流转费 8 元/人/天归来源公司）+ 平台审核（执照、许可证、甲方合同）。
6. 页尾 CTA + 页脚（联系方式用「400-xxx-xxxx」这类明显占位，ICP 备案号用占位）。

### 4.2 公司后台 · 驻场工作台（桌面 1440×900，一屏不滚动）
结构照搬 `a2-list-detail.html`（用户认可的布局）：左侧侧栏 → 顶部标题与搜索 → 5 个数字卡片 → 左「今日待办」列表（按剩余时间、阶段筛选）+ 右「选中人的详情」（进度条、超时提醒、报名信息、匹配记录、求职画像、处理记录、主按钮）。保留它的交互（点人切换详情、阶段筛选、倒计时走动）。

### 4.3 驻场手机端 · 工作台（手机 390×844）
顶部：王磊 · 驻场老师、鑫诚劳务 · 立讯精密昆山二期、通知铃。→ 4 个数字（今日到厂 7、待面试 9、待确权 4、本月入职 62）→ 一条超时提醒（「3 人即将超时，最短还剩 00:42」+「立即跟进」）→「今日待办」卡片列表（每张：姓名 + 归属标签 + 剩余时间；岗位与面试时间；手机号；底部「拨打」次按钮 + 阶段主按钮）→ 底部标签：工作台 / 待办 / 提醒 / 我的。可滚动。点主按钮有轻提示即可。

### 4.4 求职者端（手机 390×844，两张）
- **首页**：顶部问候「张浩，你好」+ 状态「自由求职 · 可匹配全平台岗位」；一张主卡片「还没找到活儿？7 道题，1 分钟，给你 3 个岗位」+ 主按钮「开始匹配」；4 个入口宫格（AI 问薪、薪资预支［在岗后可用，置灰并写明原因］、我的报名、工资条［入职后可用，置灰］）；「平台保障」一行（实名核验、电子合同、驻场 24 小时联系）；「最近动态」空状态（「完成匹配后，报名进度会显示在这里」）；底部标签：首页 / 我的报名 / 消息 / 我的。
- **匹配结果**：顶栏返回 +「为你匹配的 3 个岗位」+ 右侧「重新匹配」；一行说明「从中选 1 个报名，报名后驻场老师 24 小时内联系你」；3 张岗位卡片（职位名 + 匹配度、薪资大字、福利灰标签、地点与剩余名额、推荐理由［只第一张］、公司 · 劳务公司、按钮「查看并报名」）；底部「都不满意？重新匹配，次数不限」。

## 5. 文件约定

- 每个界面一个目录：`site/`、`console/`、`staff/`、`seeker/`。每个画面三个文件：`<画面>-d1.html`、`<画面>-d2.html`、`<画面>-d3.html`，三个文件的 HTML 结构和文字完全一致，只有 `<style>` 里的变量和组件样式不同。
- 单文件、自包含：CSS 和脚本内联，不引用网络资源和目录外文件。文件顶部写注释 `<!-- PROTOTYPE — 可删除 ... -->`。
- 画面上不出现「示例」「原型」「未接入」等制作说明。
- 每个文件用 Chrome 无头模式截图到该目录的 `shots/`：桌面 `--window-size=1440,900 --force-device-scale-factor=2`；手机 `--window-size=390,844 --force-device-scale-factor=3`（手机页面要在 390 宽下正常排版，`body` 不设最小宽度）。官网额外截一张整页长图（`--window-size=1440,4200`）。
