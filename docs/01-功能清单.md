# 01 · V1.0 功能清单

> 优先级：**P0** = 商业闭环必需，缺一不可上线；**P1** = V1.0 必须交付，可排在后段 Sprint；**P2** = 原型「规划外补充」或体验增强，资源不足时可顺延。
> 版本：`1.0` 本期开发；`1.0-预留` 只做入口 / 占位；`1.5` 不进入本期。
> 原型编号：`S-xx` C 端 app.html，`M-xx` 驻场端 staff.html，`A-xx` 公司后台 admin.html，`P-xx` 平台中台 platform.html。

## 0. 全局业务规则（所有端共同遵守，作为验收基线）

| 编号 | 规则 |
|---|---|
| R-01 | **匹配是唯一入口**：无岗位列表浏览；岗位只出现在 AI 问薪结果中，仅结果内岗位带「报名面试」按钮 |
| R-02 | **固定输出 3 个岗位**；匹配度 ≥80% 才展示百分比；无 ≥80% 岗位 → 转人才经纪人 |
| R-03 | **报名前可无限次重新匹配；报名后不可再匹配、不可再报名**，直到面试结果产生或被释放 |
| R-04 | **用户不可自行取消报名**，只能由驻场 / 项目经理在后台取消 |
| R-05 | `source_company_id` 注册时按渠道锁定，**永不更改**，唯一决定流转费 80% 归属 |
| R-06 | `bound_company_id` 为空 = 公域，非空 = 私域；公私域为派生值，不落库 |
| R-07 | 私域 → 公域只有两条路径：**释放**（主动 / 24h 超时被动 / 面试未过 / 确权超时 / 取消 / 爽约）与**离职**。用户不能自己变公域；企业不能在在岗期间单方面置公域 |
| R-08 | 私域用户（含报名后的临时私域）每个阶段完成后享有 **24h 专属响应窗口**，超时系统被动释放为公域；公域用户不触发 |
| R-09 | **入职确权是唯一官方统计节点**，同时是两项计费的起点；离职即停止，无上限 |
| R-10 | 增长技术服务费 V1.0 统一 **0.10 元/人/天**（阶梯属 V1.5）；三个月免费期，期满锁定存量基数，存量永久免费 |
| R-11 | 人才流转费 **10 元/人/天**，接收方付；来源方 8 元 / 平台 2 元；来源为平台或来源公司已注销 → 10 元全归平台 |
| R-12 | 每一次用户状态迁移都写 `user_status_log`（操作人、原因、时间、IP），释放 / 取消必须有操作人或系统原因码 |
| R-13 | 敏感信息（手机号、姓名、身份证）加密存储；驻场可见完整手机号；项目经理隐藏手机与证件；老板仅聚合数据 |
| R-14 | 降权 / 限流对企业和用户**均不可见**，仅平台中台可查看真实权重 |
