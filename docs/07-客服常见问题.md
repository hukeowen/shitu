# 07 · 客服常见问题

> 给平台客服和劳务公司驻场用：遇到问题先查这里，口径与 [04-决策记录](04-决策记录.md) 一致；规则有变动以决策记录为准。
> 回答求职者时不要提「私域 / 公域 / 确权」等内部词，用括号里的说法。

## 一、求职者（C 端）

### 注册与登录

**Q：收不到验证码？**
同一手机号 60 秒内只能发一次；连续发送会要求先做图形验证。请确认手机号正确、没有被拦截短信。仍收不到的，记录手机号和时间，转平台排查短信日志。

**Q：要不要设密码？**
不用。每次用手机号 + 短信验证码登录；没注册过的手机号验证后自动注册。

**Q：换了手机号怎么办？**
新号码直接登录会变成一个新账号。实名时如果提示「证件已被其他账号绑定」：
- 旧号码还能收短信 → 点「找回旧号」，用旧号码登录，原来的报名和工作记录都在旧账号里；
- 旧号码已停用 → 点「提交申诉」，平台 5 个工作日内人工复核。通过后解除旧账号实名，用新号码重新实名即可。旧账号还在面试、待入职或在岗时不能解除，需要先办完离职或取消报名（D-45）。
- 不是本人注册的 → 点「举报冒用」，同样走人工复核。

> 客服不能告诉求职者旧账号的手机号，哪怕是部分号码（D-48）。

**Q：我是扫某个老师的二维码注册的，后来又扫了别家公司的码，会变吗？**
不会。首次注册时扫的码决定由哪家公司服务你，之后再扫其他码不改变（C-105 / C-106）。

### 找工作、报名

**Q：匹配结果为什么少于 3 个 / 一个都没有？**
只展示匹配度 80% 以上的岗位（D-39）。可以调整期望（地区、薪资、住宿等）重新匹配；扫公司码注册的用户会由该公司顾问人工跟进。

**Q：报名后能不能换岗位？**
自己不能再次匹配（D-07）。需要联系驻场老师取消当前报名，然后重新匹配。

**Q：为什么报名前要实名？**
劳务合同和工资发放都需要真实身份。一个身份证只能绑定一个账号；未满 16 周岁不能注册实名，16–18 周岁可以实名但不能报名（D-15）。

**Q：报名后多久有人联系？**
驻场老师需要在 24 小时内处理。超过 24 小时没人跟进，系统自动释放（求职者可以自由选择全平台岗位），会收到短信通知（D-06）。

**Q：面试没通过 / 没去面试怎么办？**
可以重新匹配其他岗位。扫公司码注册的用户面试没通过，仍由原公司继续服务（D-31）。

### 签约、在岗、离职

**Q：签约链接打不开 / 过期了？**
请联系驻场老师在后台「重发签约」，新链接会推送到消息中心（按通知模板配置同时发短信），也可以在「我的合同」里找到待签署的合同；驻场老师也可以当面出示签署码让你扫。签约完成才算正式入职。

**Q：怎么离职？**
联系驻场老师办理，项目经理审核确认。离职当天起停止服务费计算；有预支欠款的会从最后一笔工资里抵扣（D-22）。离职后可以重新找工作。

**Q：「我的工作」里看不到公司名？**
首页身份卡只显示状态，点进「我的工作」才显示所属公司（C-502）。

### 薪资预支

**Q：为什么不能预支？**
需要同时满足 5 项：在岗；有所属公司；在岗满 7 天；本月用了不到 4 次；还有剩余机会（C-602）。在岗天数从入职日算起，扣除请假和旷工（D-27）。

**Q：预支机会怎么算？**
入职满 7 个在岗日解锁第 1 次，之后每满 7 个在岗日加 1 次；每月最多 4 次，没用完的月底清零（D-26）。每次固定 500 元。

**Q：预支多久到账？**
驻场初审 → 项目经理终审 → 拨款，三步都在「预支进度」里能看到。任何一步驳回，本次机会退回。

**Q：预支怎么还？**
发薪时从工资里自动抵扣，工资条上有「预支抵扣」一项。一次工资不够扣的，下个月继续扣；多笔预支按先借先还（D-47）。

### 工资、投诉、实名

**Q：工资条不对？**
在工资条详情点「申诉」，说明哪一项不对，由公司后台处理。工资由劳务公司发放，平台不代发（D-28）。

**Q：岗位信息和实际不符？**
在岗位详情点「投诉」，选择原因并补充说明 / 图片。平台核实后处理；同一岗位投诉属实 3 次会自动下架并扣企业诚信分。

**Q：提示「平台失信」？**
有未结清预支、欺诈或恶意行为会被列入平台失信名单，不能报名和预支。各公司只能看到「失信」标记，看不到原因（D-16）。可以在实名页提交失信申诉，5 个工作日内复核。

## 二、劳务公司成员（公司后台 / 驻场端）

**Q：怎么入驻？**
用手机号 + 短信验证码登录公司后台；不是任何公司成员的手机号会进入入驻流程，上传营业执照和人力资源服务许可证提交审核。提交人即为老板账号（D-33）。

**Q：一个手机号能加入两家公司吗？**
不能，成员手机号全平台唯一。但同一个手机号可以同时用 C 端找工作，两套账号互不影响（D-36）。

**Q：成员看不到某个项目的数据？**
驻场和项目经理只看自己负责的项目，由老板在「组织与权限」里分配。手机号只有驻场能看到完整号码，其他角色看到的是脱敏号码。

**Q：改了岗位为什么下架了？**
修改薪资、职责、食宿等信息要重新经过平台审核，审核期间不参与匹配；只调名额不用审核（D-34）。

**Q：名额什么时候扣、什么时候回？**
报名时扣；取消、爽约、面试未通过、超时都自动回补（D-12）。

**Q：24 小时窗口怎么算？**
新报名、私域新注册、面试通过后待入职，都有 24 小时处理时限。白天（08:00–22:00）每 6 小时提醒一次，夜间每 12 小时一次（D-14）。超时自动释放，本公司失去这个求职者。来不及处理的，可以一键流转给人才经纪人。

**Q：员工离职了，账单还在算？**
离职必须在后台审核确认后才停止计费；离职日当天不计费（D-20）。请及时在「离职审核」里处理。

**Q：服务费怎么算？**
入驻后 3 个月免费；免费期最后一天的在岗人数锁定为存量基数，之后只对超出基数的部分按每人每天 0.10 元计费（D-18 / D-42）。存量员工永久免费，所以免费期内请把现有员工通过「花名册导入」录入。

**Q：账单有异议？**
在「费用账单」里对当月账单提出异议，5 个工作日内（按法定工作日）处理（D-23）。

**Q：渠道转化里「访问」比注册少 / 多？**
「访问」是按人去重的扫码人数，同一个人多次扫码只算 1 次；带码直接注册的也会计入访问（D-49）。

## 三、转平台处理的情况

以下情况客服不直接处理，记录后转平台运营（运营中台对应模块）：

| 情况 | 转给 | 需要记录 |
|---|---|---|
| 证件被占用 / 失信申诉超过 5 个工作日未处理 | 实名复核 | 手机号、申诉提交时间 |
| 企业对处罚 / 诚信分有异议 | 风控 | 公司名、处罚记录时间 |
| 账单金额与在岗人数对不上 | 计费 | 公司名、账单月份、对不上的日期 |
| 签约回调失败（已签但状态未变） | 技术 | 报名编号、合同编号、签署时间 |
| 短信长时间收不到 | 技术 | 手机号、发送时间 |
