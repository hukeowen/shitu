# 08 · 试点上线手册

> 1–2 家试点企业从开通到正常运转的操作步骤。技术部署见 [06-运维手册](06-运维手册.md)，答疑口径见 [07-客服常见问题](07-客服常见问题.md)。

## 1. 企业开通（第 1 天）

1. **老板入驻**：老板用本人手机号登录公司后台 → 填写公司信息、上传营业执照与人力资源服务许可证 → 提交。
2. **平台审核**：运营中台「公司管理」里的待审核当天处理，驳回要写明原因。
3. **组织与成员**：老板在「组织与权限」里添加项目经理、驻场、人才经纪人，并给每人分配负责的项目。
   - 成员手机号全平台唯一，已是其他公司成员的号码加不进来。
4. **项目、甲方、合同**：在「项目与甲方」建项目、关联甲方（用工单位）、上传合作合同并提交平台备案。
5. **岗位**：按项目发布岗位（薪资、班次、食宿、名额、面试地点）→ 运营中台「岗位审核」通过后才参与匹配。

## 2. 存量员工（免费期内必须完成）

> 免费期最后一天的在岗人数会锁定为存量基数，存量员工永久免费。**存量员工没导入，免费期满后就会被当作新增计费。**

1. 项目经理下载花名册模板 → 按模板整理现有员工（姓名、身份证、手机号、项目、入职日期、工号）。
2. 「花名册导入」上传 → 逐行查看结果；失败行按原因修正后只上传失败行。
3. 运营中台「花名册与存量锁定」核对人数，告知企业免费期截止日。
4. 免费期满次日系统自动锁定基数；锁定后企业在「费用账单」能看到基数。

## 3. 渠道码投放

1. 每位驻场 / 经纪人在驻场端「我的专属码」有个人码；也可以在公司后台「渠道二维码」按项目或活动生成。
2. 投放位置：厂区招聘点、宿舍、合作中介、微信群。印刷前用微信扫一次确认能正常打开。
3. 扫码注册的求职者归属本公司，**24 小时内必须跟进**，否则自动释放。投放前确认有人值守。
4. 老板在「渠道转化报表」里看各码的访问 → 注册 → 报名 → 入职。

## 4. 驻场培训（约 1 小时，现场带着手机操作）

| 环节 | 内容 | 练习 |
|---|---|---|
| 登录 | 驻场端用公司开通的手机号登录；添加到手机桌面 | 每人登录一次 |
| 待办 | 待知悉 → 点「知悉」推送面试信息；待面试；今日到厂；待确权 | 用测试求职者走一遍 |
| 到厂与面试 | 到厂确认 → 录入通过 / 未通过；没来的标记爽约 | 各操作一次 |
| 签约 | 确权（岗位、入职日期、工号）→ 发起电子签 → 出示签署码或让求职者在消息里签 | 走一份真实合同 |
| 24h 提醒 | 看倒计时，处理不过来就一键流转给经纪人 | — |
| 预支初审 | 看准入条件与在岗日 → 通过 / 驳回（驳回要写原因） | — |
| 请假旷工 | 按人按日标记，会扣减在岗日，影响预支机会 | — |
| 不要做的事 | 不截图、不外传求职者完整手机号；不代替求职者签约 | — |

项目经理另加：预支终审、离职审核、工资表导入、知识库（岗位常见问题）补充、看板。
老板另加：总览、渠道转化、费用账单与异议、流转账本。

## 5. 试点期间每日检查（平台运营，前两周）

- 运营总览：新注册、报名、入职是否有数；为零的企业当天电话回访。
- 24h 响应监控：本日超时释放数，超时多的企业提醒加人值守或用经纪人流转。
- 发件箱死信为 0；短信发送失败率。
- 待处理：公司 / 岗位审核、合同备案、实名与合规复核、知识库待补充、投诉。
- 收集问题：驻场 / 求职者反馈按「功能缺陷 / 使用问题 / 新需求」三类记录，每周汇总。

## 6. 试点退出标准（转正式推广）

- 连续 2 周无 P0 缺陷（数据错误、计费错误、越权、无法登录 / 签约）；
- 首月账单与企业自己的在岗记录逐日核对一致；
- 24h 超时释放率低于 20%；
- 主流安卓低端机和 iOS 真机上，扫码 → 注册 → 实名 → 报名 → 签约全程走通。
